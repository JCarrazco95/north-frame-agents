# Remotion — plantilla de marca North Frame

Aún sin inicializar. Primera vez (lo hace `editor-remotion` con la aprobación de quien esté en sesión):

```bash
cd remotion
npx create-video@latest . --blank
npx skills add remotion-dev/skills
```

Componentes de marca a crear en `src/marca/`:

| Componente | Qué hace |
| --- | --- |
| `EtiquetaIA` | "Contenido generado con IA", esquina superior, legible en móvil, dentro de zona segura |
| `TextoGancho` | Texto de 3–6 palabras en el primer segundo, tipografía de marca |
| `Remate` | Tarjeta naranja 2 s con nombre del candidato y línea final |
| `Subtitulos` | Captions desde la transcripción de Whisper |
| `ZonaSegura` | Guía visual (solo en preview) de márgenes de TikTok/Reels |

Render estándar: 1080x1920, 30 fps, H.264, sin música con derechos.
Licencia: Remotion es gratis para personas y empresas pequeñas; revisa en remotion.dev/license si North Frame requiere licencia de empresa.
