# Glosario North Frame

Una línea por término. Los agentes agregan términos nuevos cuando los usan por primera vez.

| Término | Qué es |
| --- | --- |
| Agente / subagente | Un "asistente especializado" de Claude con una sola tarea (ej. guionista). El orquestador los coordina. |
| Orquestador | La sesión principal de Claude (modelo Opus): reparte el trabajo y revisa. |
| Opus / Sonnet / Haiku | Modelos de Claude: Opus el más capaz (revisa y decide), Sonnet creativo, Haiku rápido y barato (tareas mecánicas). |
| Compuerta | Punto de revisión obligatorio antes de seguir; la hace `revisor-opus`. Hay 3 por pieza. |
| Trend | Formato que se está repitiendo en redes (baile, audio, reto) y que podemos adaptar. |
| Arquetipo | El tipo de trend: baile, celebración deportiva, stunt, etc. |
| Palanca psicológica | Lo que hace que alguien se detenga y recuerde (asombro, humor, identidad local…). |
| Gancho | Lo que pasa en el primer segundo para frenar el scroll. |
| Clímax | El momento más fuerte del video; casi siempre es la portada. |
| Remate | Los últimos 2 s con la firma de Iván. |
| Loop | Que el final conecte con el inicio para que el video se repita solo. |
| Prompt | La instrucción escrita que le damos a un modelo de IA para generar una imagen o video. |
| Keyframe | Imagen fija que sirve de punto de partida para generar un video. |
| Soul ID | Función de Higgsfield que "aprende" el rostro de Iván para que salga igual en todas las tomas. |
| Toma | Cada intento de generar un mismo plano; generamos 3–4 y elegimos la mejor. |
| Plano | Un fragmento continuo del video entre dos cortes. |
| Render | Exportar el video final ya editado. |
| Remotion | Herramienta que arma y exporta los videos con código (la usa `editor-remotion`). |
| 9:16 | Formato vertical de celular (1080x1920). |
| LUFS | Medida de volumen; en redes usamos -14 LUFS para que no suene ni bajo ni saturado. |
| Créditos | Lo que cobra Higgsfield por cada generación. |
| Repo / git / GitHub | La carpeta compartida del proyecto con historial de cambios; GitHub es donde vive en internet. |
| /sync y /cerrar-sesion | Comandos para empezar y terminar: bajan y suben los cambios y actualizan monday. |
| Etiqueta IA | Leyenda "Contenido generado con IA" obligatoria en todas las piezas. |
| Veda | 3–5 de junio de 2027: no se publica nada. |
