# Guía de inicio (para quien no ha usado nada de esto)

Tiempo: unos 30 minutos la primera vez. Después, solo el paso "Cada día".

## Una sola vez

1. **GitHub**: crea una cuenta en github.com y pásale tu usuario a Coque. Te llegará un correo de invitación al
   repositorio `north-frame-agents`: acéptala.
2. **monday**: acepta la invitación al workspace "North Frame". Usa el mismo correo que vas a usar en git.
3. **Claude**: inicia sesión en claude.ai con tu propia cuenta (no compartan cuenta).
4. **App de escritorio**: descarga Claude Desktop (claude.com/download), inicia sesión y abre la pestaña **Code**.
5. **Git** (solo Windows): si la app te lo pide, instala Git desde git-scm.com aceptando todo por defecto.
6. **Abrir el proyecto**: en la pestaña Code, elige abrir un repositorio de GitHub y selecciona
   `JCarrazco95/north-frame-agents`, o pídele a Claude: "clona el repo JCarrazco95/north-frame-agents en mi carpeta
   Documentos y ábrelo".
7. **Tu correo en git**: escribe a Claude: "configura mi correo de git como <tu correo de monday> solo para este repo".
8. **Modo aprendiz**: escribe `/output-style` y elige **Aprendiz North Frame**. Claude te explicará todo mientras trabaja.
9. **Conexiones**: la primera vez que Claude use monday o Higgsfield te abrirá una ventana para autorizar. Acepta con
   la cuenta del equipo.
10. **Carpeta de videos**: Coque te compartirá la carpeta de media. Pídele a Claude: "enlaza la carpeta compartida
    <ruta> como media/ en este repo".

## Cada día

1. Abre la app → Code → proyecto north-frame-agents.
2. Escribe `/sync`. Claude te dice qué hay y qué puedes tomar.
3. Trabaja: `/nuevo-trend`, `/producir`, `/revisar`, o `/practica` para ejercicios.
4. ¿No entiendes algo? `/explicame <lo que sea>`.
5. Al terminar: `/cerrar-sesion`. **Nunca te vayas sin esto**: así Coque ve lo que hiciste.

## Reglas para no pisarse
- Si una pieza en monday tiene a Coque en "Tomado por", no la toques.
- Si Claude te propone cambiar un agente o un archivo de `docs/contexto/`, va como propuesta (PR) para que Coque la revise.

## Si algo sale mal
Escribe a Claude exactamente lo que ves ("me salió un error rojo que dice…") y pídele: "explícame qué pasó y arréglalo
sin perder nada". Si sigue, avisa a Coque antes de borrar cualquier cosa.
