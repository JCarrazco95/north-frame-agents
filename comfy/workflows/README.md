# Workflows de ComfyUI (ruta local)

Exporta aquí los workflows en formato API (ComfyUI → Workflow → Export (API)) con estos nombres:

- `wan22_i2v.json` — Wan 2.2 imagen a video
- `wan22_t2v.json` — Wan 2.2 texto a video (b-roll)
- `ltx23_t2v.json` — LTX-2.3 con audio
- `qwen_image.json` — keyframes

El `operador-local` reemplaza en ellos: prompt, negative, semilla, resolución y número de cuadros.
Mientras esta carpeta no tenga workflows, todos los planos van por la ruta Higgsfield.
